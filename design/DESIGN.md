# MotionForge UI spec (match reference/ui-reference.png)

Open the reference image first. This file describes it region by region. Where this text and the image
disagree, the image wins. Dark theme only for v1. Desktop layout, designed at 1536x1024, fluid down to 1280 wide.

## Global
- Page: --bg-app. All panels are --bg-panel, 1px --border, radius 12-16px, no heavy shadows.
- Font: Inter for UI, JetBrains Mono for terminal, file names, timecodes and paths.
- Icons: lucide-react, 18px, stroke 1.75, color --text-dim (white when active).
- Primary buttons: solid --primary, white text, radius 10px, height 40px. Secondary: --bg-panel-2 with --border.
- Pills/badges: radius 999px. Green status dot + text for Running, Connected, Ready.

## Top bar (height 56px, full width)
- Left: logo mark (blue play-triangle in rounded square) + "MotionForge" (semibold 20px) + faint tagline "Ideas -> Videos, with AI".
- Right: "Local Server Running" (green dot), "Connected to Antigravity" (outlined pill with cloud icon), settings gear, round avatar with initial.

## Left sidebar (207px)
- Nav items: Home (active: filled --primary-bg row, white icon), Projects, Styles, Assets, Agent, Settings.
- Bottom group "Quick Actions": New Project (primary), Open Folder (secondary), MCP Tools (secondary).
- Footer tagline, faint: "Better prompts. Better visuals. With your AI agent."

## Project header
- Project name (22px semibold) + pencil icon, path under it in mono faint text.
- Phase pill "Phase 1: Storyboard" (blue outline).
- Right: "Last saved 2 min ago", Save (secondary), Generate Preview (primary, wide).

## Stepper (4 steps, in a bordered strip)
1 Upload & Score (done: green check) -> 2 Storyboard (current: blue filled number) -> 3 Assets & Voice -> 4 Render.
Each has a title and a faint subtitle. Connector lines between steps; the completed segment is blue.

## Main grid (3 columns)
Left column (~285px):
- Card "1. Upload Your Media": dashed drop zone with cloud-upload icon, "Drag & drop files here / or click to browse",
  "Supports: MP4, MOV, JPG, PNG, etc." Below it a file list: 48px thumbnail, mono name, size, X to remove.
- Card "2. Choose a Style": 3x2 grid of thumbnail tiles with label under; selected tile has blue ring and blue check badge.
  Link "View All Styles ->".
Center column (flex):
- Card "3. Storyboard" + subtitle, "Edit with Agent" button top right.
  Scene rows: 120x72 thumbnail, "1. Opening Shot (0:00 - 0:04)", description, right-aligned chips
  (media type like "Image + Video", "Style: Cinematic") and a ... menu. "+ Add Scene" button and "Total Duration: 28s" at the bottom.
Right column (~385px):
- Preview card: title, HD badge, 16:9 video player with controls (play, time, scrubber, volume, captions, fullscreen).
- Style Settings card: style dropdown, Aspect Ratio / Resolution / Duration selects.
- Voice & Captions card: "Ready" badge, voice row (waveform icon, "Kokoro (English)", Change button),
  toggles for Auto Captions, Background Music, Sound Effects, then a primary "Go to Asset Prep ->" button.

## Bottom dock (three panels in one row)
1. Agent Bridge: header with "Connected" badge and collapse chevron; tabs "MCP Tools" / "CLI Terminal";
   one-line help text; 5 tool tiles (list_assets, score_styles, prep_clip, generate_voice, render) each with icon,
   name, tiny description; "View MCP Config" button.
2. Antigravity CLI (Live, Running): mono terminal output stream with timestamps, input box "Type a message or command..." + send icon.
3. Project Folder: path, file rows (brief.md, assets/, storyboard.json, style.json, render.mp4 with Pending), size and time columns,
   footer note "The agent reads and writes to this folder."

## Behaviour that must be visible in the UI
- Every status chip reflects real state (server health, agent connection, job progress), not hard-coded text.
- Stepper advances only when that phase's output files exist.
- Terminal streams live over WebSocket; scene rows and project folder update when files change on disk.
- Thumbnails are generated by FFmpeg from the user's own uploads (never stock images).

## Note on styles
The reference shows generic style tiles (Cinematic, Modern, Vintage, Anime, Documentary, Minimal). In the real app the tiles
are the seven styles from the playbook: Kinetic Type, Chalk Talk, Clean Tech, Software Walkthrough, Data Story, Warm Canvas, Pop Info.
Keep the tile layout; each tile shows a code-rendered preview of that style, not a photo.

## Edit step (added in Phase 4, no reference image yet)
- Stepper has five steps: Upload & Score, Storyboard, Assets & Voice, Edit, Render.
- The Edit screen replaces the 3-column main grid with: preview player top, multi-track timeline below (video, overlays, captions, voice, music),
  a media/scenes panel on the left and an inspector on the right. The bottom dock (Agent Bridge, Antigravity CLI, Project Folder) stays.
- Use the same tokens, panels, radius, icons and fonts. Theme the embedded openreel-video UI to match; do not leave its default look.
